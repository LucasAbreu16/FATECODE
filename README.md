📚 FateCode - Plataforma de Grupos de Estudos
Sobre o Projeto

O FateCode é uma plataforma web desenvolvida como projeto acadêmico com o objetivo de facilitar a criação e participação em grupos de estudos. A aplicação permite que estudantes encontrem colegas com interesses em comum, promovendo a colaboração, o compartilhamento de conhecimento e a organização dos estudos em grupo.

Embora o tema principal seja a formação de grupos de estudo, o foco do projeto foi aplicar na prática os conceitos fundamentais de desenvolvimento web, incluindo estruturação de páginas, estilização, navegação, responsividade e interação entre usuários.

Objetivos
Objetivo Geral

Desenvolver uma aplicação web para conectar estudantes interessados em formar grupos de estudos.

Aplicar conceitos de front-end e back-end.

Desenvolver interfaces intuitivas e responsivas.
Utilizar ferramentas modernas de desenvolvimento web.
Realizar deploy da aplicação em ambiente online.
Funcionalidades
